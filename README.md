# Kushal Vadhar - macOS Inspired Portfolio 🚀

A high-performance, responsive portfolio website built with **Flutter Web**, featuring a premium macOS-style user interface.

## ✨ Features
- ** macOS Desktop Experience**: Interactive windows, top bar menus, and a functional dock.
- **📱 True Responsiveness**: Seamlessly transitions from a desktop OS feel to a mobile-optimized single-page layout.
- **📂 Spotlight Search**: Functional `Cmd+K` / `Ctrl+K` search for quick navigation.
- **🎨 Glassmorphism Design**: Modern, sleek aesthetics with real-time blur and depth.
- **🌓 Adaptive Theme**: Dynamic wallpapers and interactive system components.
- **📬 Functional Contact Form**: Validated inputs with immediate user feedback.

## 🛠️ Tech Stack
- **Framework**: [Flutter](https://flutter.dev) (Web)
- **State Management**: Provider
- **Animations**: Flutter Animate & Custom Painters
- **Icons**: FontAwesome & Cupertino Icons
- **Hosting**: Recommended via Vercel or GitHub Pages

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (stable channel)
- A modern web browser

### Installation
1. **Clone the repository**
   ```bash
   git clone https://github.com/KushalVadhar/kushal-portfolio.git
   ```
2. **Install dependencies**
   ```bash
   flutter pub get
   ```
3. **Run locally**
   ```bash
   flutter run -d chrome
   ```
